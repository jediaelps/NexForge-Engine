# 🎯 About the Project

NexForge Engine is a personal project created to make game development easier and more intuitive.

The engine is being developed from scratch using Python, with the goal of allowing developers and beginners to create 2D and future 3D games using a visual and simplified workflow.

This project represents my passion for software development, game creation, and user-friendly tools.

---

# ✨ Current Features

- Visual editor
- Object inspector
- Scene management
- Drag and drop support
- JSON-based structure
- Real-time object editing
- Modular project structure

---

# 🚀 Future Goals

- 3D support
- AI-assisted development tools
- Visual scripting system
- Game exporter
- Plugin system
- Steam-ready game deployment
- Multiplayer support
